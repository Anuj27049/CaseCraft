
# CaseCraft 🔍

**Look closer. Think deeper. Find the truth.**

CaseCraft is a Java-based detective investigation game where you solve mysteries by exploring crime scenes, collecting evidence, interrogating suspects, and identifying the culprit.

## Features

- 5 unique mystery cases
- Interactive crime scene investigations
- Suspect profiles and interrogations
- Evidence collection and investigation notes
- Flexible accusation system
- Performance-based scoring
- Automatic progress saving

## Cases

1. The Midnight Murder
2. The Vanishing Witness
3. The Silent Server
4. A Debt in Ashes
5. The Final Testimony

## Tech Stack

- Java 17
- Object-Oriented Programming
- Java Collections
- File Handling

## Getting Started

**Prerequisite:** JDK 17 or later.

```bash
git clone https://github.com/Anuj27049/CaseCraft.git
cd CaseCraft
javac -d out src/*.java
java -cp out Main
```

On Windows, you can also launch the game using `run.bat`.
